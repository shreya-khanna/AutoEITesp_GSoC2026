# Spanish EIT Automated Scoring — Dependency Management
#
# This project uses a TWO-TIER requirements approach:
#
# 1. requirements_production.txt (RECOMMENDED for most users)
#    - Minimal install (~50 MB) for scoring new data with score_responses.py
#    - No GPU, no internet, no model downloads required
#    - Install with: pip install -r requirements_production.txt
#
# 2. requirements_research.txt (for researchers & model development)
#    - Full install for notebook experiments and reproducibility
#    - Contains: transformers, BETO, BERTScore, LLM arbitration APIs, visualization
#    - Install with: pip install -r requirements_research.txt
#
# Use requirements_production.txt or requirements_research.txt instead.
